# W2A - Design System Facil Digital+

## Objetivo

Estabelecer a fundacao visual do tema oficial
Facil Digital+ sem page builders.

## Camadas

- variables.css
- reset.css
- typography.css
- layout.css
- components.css
- header.css
- footer.css
- responsive.css

## Breakpoints principais

- Mobile: ate 640px
- Tablet: ate 1023px
- Desktop: 1024px ou superior

1180px

## Acessibilidade

A W2A estabelece:

- skip link;
- navegacao por teclado;
- focus visible;
- aria-expanded;
- aria-controls;
- Escape para fechar navegacao;
- menu responsivo;
- prefers-reduced-motion;
- labels reais em formularios.

## Responsabilidade

O tema controla somente apresentacao.

Regras de negocio permanecem no:

Facil Digital+ Core.

Produtos, pedidos, carrinho e checkout permanecem
sob autoridade do WooCommerce.
